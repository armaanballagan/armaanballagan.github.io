# Project notes for Claude

Personal portfolio site for Armaan Ballagan (UBC CS student), Undertale-themed, to be hosted on GitHub Pages at the user's `<username>.github.io` repo (Vite `base` is `./` so the build works at any path; image paths use `import.meta.env.BASE_URL`).

- Source of truth for the design: Armaan's Figma Make file "Undertale Software Engineer Portfolio". This repo is a faithful export of it.
- Stack: Vite + React 19 + TypeScript + Tailwind v4 (`@tailwindcss/vite`). No backend; static only.
- Single page with anchor navigation (`#about`, `#work`, `#experience`, `#contact`), no router.
- Content is Armaan's real info (8 projects with category filters, UBC/PNE/Delta Controls experience, email armaanballagan@gmail.com). LinkedIn: https://www.linkedin.com/in/armaan-ballagan/.
- `src/Typewriter.tsx` types dialogue text (hero on first load, project descriptions on each selection) with the `typewriter` dialogue voice from `src/audio.ts`; click to skip.
- Deploy: `.github/workflows/deploy.yml` builds `dist/` and publishes via GitHub Actions on push to `main`. Pages source must be set to "GitHub Actions".
- 18 Undertale voice clips (cut from a voice SFX video) live in `public/audio/sfx/voices/`; character voices are registered in `dialogueVoices`, laughs in `soundEffects` (not used on the page yet).
- AI covers (Armaan's own so-vits-svc voice model; Karma Police, 505, Notion, From the Start) are `aiCovers` in `src/audio.ts`, files in `public/audio/covers/` (loudnorm −16 LUFS, 128k). They play only from the special player on the AI Voice Conversion card (`renderCoverDeck` in App.tsx, where other projects have link chips). Playing one pauses the main music (`MusicPlayer.pause`); when a cover ends, or you leave that project, the main music resumes where it was (`resume`); pressing the main music button or Dogsong stops the cover.
- All sound effects and the music playlist are in `src/audio.ts` (`soundEffects`, `playlist`); App.tsx calls `playSound("name")` and `MusicPlayer`. New sounds go there with a clear label and `usedIn`.
- Gallery section (`src/Gallery.tsx`) reads photos from `src/gallery.ts` / `public/gallery/`, laid out as justified rows in list order (rows fill to a width÷height sum of 3 on desktop / 1.9 on tablet, one per row on phones; no cropping); 8 of Armaan's photos (resized to 1600px, metadata stripped).
- Hero name is Armaan's own wordmark image `public/name-logo.png` (black made transparent, cropped), revealed by the Monster Kid intro in `src/NameIntro.tsx` (sprite strip `public/undertale/monster-kid.png`, frame rects in `src/monsterKidFrames.ts`; tunables at the top of NameIntro: speeds, TRIP_AT, trip frame timings). Click the name to skip. Typing speed defaults to 22ms/char (projects 12, gallery 15); voice `rate` 1.3 in `src/audio.ts`.
- Floating sans button (`src/SansToggle.tsx`, bottom-left, fixed) mutes/unmutes typing voices; trombone sans = on, idle sans = off; saved in localStorage via `setTextVoiceMuted` in `src/audio.ts`.
- Music: 13 Toby Fox tracks (all loudness-normalized to about −16 LUFS, with per-track `volume` fine-tuned to match) in `public/audio/music/` listed in `songs` (src/audio.ts), Fisher–Yates shuffled into `playlist` on each page load. `dogsong` is separate (easter egg only).
- Dog easter egg (App.tsx `clickDog`): clicks 1–7 bark (`dog-bark.mp3`) and scale the dog +12% each; 8th click stops the playlist, plays Dogsong and swaps in `undertale/dog-meme.png`. Clicking the dog, OFF, PREV/NEXT, or Dogsong ending resets size/sprite/count.
- About section is a playable game (`src/AboutGame.tsx`): 320×240 canvas, 3 rooms traced at native res from Armaan's Undertale screenshots (`public/game/room1-3.png`: grey flower-bed cave where Frisk lands → dark corridor with the Ruins gate → walk up through the gate into the dark room with the grass patch in a spotlight, which is Flowey's spot); 4 signs total (my own sprite): 1 in the flower cave (name), 3 along the back of the corridor; Flowey's room has none (just the grass patch); room changes use `exits` zones, Frisk from the official overworld sheet (`public/game/frisk.png`, rects in `src/friskFrames.ts`). Arrows/WASD walk only while the canvas itself is ≥55% visible (checked on scroll/resize + every 500ms; clicking the canvas also activates); the game box is capped to the viewport height; Z/Enter/Space reads signs; touch D-pad on coarse pointers; falling intro on first view. About text lives in `ROOMS[].signs[].pages` (plus an sr-only copy). Dev builds expose `window.__aboutGame` for tests.
- Flowey easter egg (Stage 2, done): `src/FloweyPeek.tsx` pops Flowey's head over the top border of the Save Files box (CSS `flowey-peek` keyframes); click → full black screen + dialogue with his portrait and the `flowey` voice → `flowey.emitFound()` (`src/floweyEvents.ts`) and the page scrolls to the game. He rises on the grass patch in room 3; talking to him starts a battle drawn in the same canvas (`FIGHT` / `AFTER_HIT` step lists in AboutGame: talk / wave / ring / hurt / laugh / sink / end). Arrow keys move the SOUL in `BOX`; each dodged wave makes him angrier; getting hit drops you to 1 HP and jumps to `AFTER_HIT` → the final ring. THE ENDING (`ENDING` steps): as the ring closes, a beer can (`public/game/beer-can.png`, my own pixel art) bonks him ("Ow!" / "Huh? What's this?"), then `silenceAllMusic()` stops every site track (nothing auto-restarts), engine revs (`public/audio/asgore/engine-revs.mp3`) start and Asgore's song fades in under them while headlights brighten from the right; at `ASGORE_CUES.bump` the screen dims and the smug Asgore cut-in (`asgore-smug.jpg`) slides in; at `ASGORE_CUES.dui` the truck (`truck.png`, side view I drew, Asgore in the window from his Deltarune sheet) drives right-to-left over Flowey (squash → dust frames); the song fades out at `ASGORE_CUES.songEnd`, back to the room. Flowey stays gone until the page is reloaded (no Save Files peek). Battle sprites: `public/game/flowey-battle.png` + `src/floweyFrames.ts` (cut from Armaan's Flowey sheet); overworld Flowey `public/game/flowey-overworld.png` + `floweyOverworldFrames` come from the official overworld sheet (talk frames while he speaks, sink frames reversed to rise; grow/laugh/shrink frames are in the atlas but unused). The Save Files peek uses the yellow overworld talk frame (`public/game/flowey-peek.png`, 4x).
- Keep the pixel look: Press Start 2P / VT323 fonts, 2–4px white borders, `steps()` animations, `image-rendering: pixelated`.
